# REQUIRED design handoff

Use with [UI/UX delivery](../specialists/uiux.md#delivery-and-review) and existing
[review recording](README.md#review-recording).

- Task / manager / artifact owners / policy and candidate SHAs: REQUIRED
- User goal / chosen outputs / product constraints / decisions and rationale: REQUIRED
- Canonical flow, wireframe, visual, prototype, copy and component references: REQUIRED as scoped
- Responsive behavior / keyboard-focus / accessibility / loading-empty-error-recovery states: REQUIRED
- Assets / tokens / language-tone standards / implementation instructions: REQUIRED as scoped
- Evidence classification: actual research, observed data, hypothesis, simulation: REQUIRED
- Validation scenarios/results and limitations / untested behavior: REQUIRED
- Independent review records by expertise, findings/disposition: REQUIRED
- Prepared / validated / applied status and evidence: REQUIRED
- Prototype vs production status / code review-test gates / integration owner: REQUIRED
- Open questions / next actions / owner / manager acceptance: REQUIRED
