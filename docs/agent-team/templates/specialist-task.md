# REQUIRED specialist task

Use with the existing [brief](brief.md), [status/result records](README.md) and
[shared specialist policy](../specialists/README.md). These are additional fields,
not replacements for base SHA, scope, approvals, review or closure requirements.

- Team / objective / selected outputs / acceptance criteria: REQUIRED
- Specialist manager / repository owner / coordinator or human-designated task coordinator: REQUIRED
- Status writer / canonical artifact paths and owners / report paths: REQUIRED
- Parent and dependency tasks / conflicts checked / repository identities: REQUIRED
- Policy full SHA / configured enabled profile / frozen complete role-model-options mapping: REQUIRED
- User default/override evidence / primary executor / provider-constraint check: REQUIRED
- Host binding / candidate full SHA / allowed files / sandbox or target environment: REQUIRED
- Global ledger reservation / running vs waiting roles / stricter capacity limit: REQUIRED
- Required skills and project standards / proposed standard changes: REQUIRED or none
- Test or design validation scenarios / review roles and exact evidence expected: REQUIRED
- Live-operation authority, allowed targets/actions and remaining gates: REQUIRED or none
- Operational targets (availability, downtime, data loss, recovery) or design constraints: REQUIRED as applicable
- Predecessor/successor / carried findings and correction count: REQUIRED or none

## Progress and final handoff

- Timestamp / decisions and reasons / problem and attempted solution / next owner: REQUIRED
- Prepared artifacts and SHAs: REQUIRED
- Validated checks, commands/scenarios, candidate/environment and evidence: REQUIRED or not run
- Applied operations, exact targets and authorization: REQUIRED or not applied
- Review reports, unchanged verdicts, open findings/owners and exceptions: REQUIRED
- Assumptions / limitations / remaining user decisions / continuation checkpoint: REQUIRED
- Observed time/usage with source, or unknown: REQUIRED
- Manager acceptance and user summary / closure readback: REQUIRED when complete
